kapps_triplestore_interface.store#

The contract of a store, and where a store is.

The layers above the interface type a store as TripleStore, and they build one with connect(), from a TripleStoreEndpoint and an auth provider. They never name the class of a store’s adapter.

class kapps_triplestore_interface.store.TripleStore(*args, **kwargs)[source]#

Bases: Protocol

A store, as the layers above the interface use it.

It declares each operation that the object-graph mapper, the middleware and the use cases call on a store, measured in their code, and no other. The GraphDB adapter, GraphDB, implements it; each operation is documented there. A test double implements it without inheriting from it.

  • Reads: query, triple_exists, triples_get, iri_exists, is_subclass, owl_get_classes_of_individual, graph_get.

  • Writes: triple_add, triple_delete, triples_add, triples_delete, triples_update, graph_add, graph_clear, and query with update=True.

  • Names: new_iri.

  • The store’s registries, which SPARQL does not cover: the dataset’s prefixes, prefixes_get, prefix_set and prefix_delete, and its SHACL shapes, shapes_set.

  • The store itself: its dataset, and close.

A store that has no such registry raises TripleStoreNotSupportedError for its operations, and they are never a silent no-op. An adapter that inherits this type and does not implement a registry raises it from the operations declared here.

prefixes_get() → Dict[str, str][source]#

Each prefix of the dataset, with the namespace IRI that it stands for.

The empty prefix, if the dataset has one, is the key “”.

Raises:

TripleStoreNotSupportedError – If the store has no prefix registry.

prefix_set(prefix: str, iri: str) → None[source]#

Let prefix stand for the namespace iri in the dataset.

A prefix that the dataset has already stands for iri afterwards. “” is the empty prefix.

Raises:

TripleStoreNotSupportedError – If the store has no prefix registry.

prefix_delete(prefix: str) → None[source]#

Remove prefix from the dataset. Every other prefix stays. “” is the empty prefix.

Raises:

TripleStoreNotSupportedError – If the store has no prefix registry.

shapes_set(data: str, content_type: str) → None[source]#

Replace the SHACL shapes that the store validates the dataset against with data.

content_type is the media type of data, for example text/turtle. An empty document removes every shape.

Raises:

TripleStoreNotSupportedError – If the store has no shapes registry, or the dataset has no SHACL validation. The shapes would otherwise be stored as data that validates nothing.

class kapps_triplestore_interface.store.TripleStoreEndpoint(url: str, dataset: str)[source]#

Bases: object

Where a store is: its URL and its dataset. It holds no secret, so it can be logged.

Parameters:

  • url (str) – The base URL of the store, for example http://localhost:7200.

  • dataset (str) – The dataset that the store’s operations act on. GraphDB calls it a repository.

classmethod from_env(dataset: str | None = None) → TripleStoreEndpoint[source]#

The endpoint that the environment names.

Reads TRIPLESTORE_URL and, unless dataset is given, TRIPLESTORE_DATASET. GRAPHDB_URL and GRAPHDB_REPOSITORY are their deprecated fallbacks: a value read from one of them emits a DeprecationWarning.

Parameters:

dataset (Optional[str]) – The dataset. When given, no variable is read for it.

Raises:

ValueError – If a variable is missing. The message names it.
